## Taiwan ETF Lookthrough

[Taiwan ETF Lookthrough v1.2.0](skills/taiwan-etf-lookthrough/SKILL.md) 使用有來源與持股日的官方快照，整理台股公司曝險、產業分布與持股重疊；新增 00982T、00981T、00735、00980T 的混合／跨市場 ETF 台股現貨分析，保留海外股票與未知值。
內附 2026-10-22 的固定歷史假設示範；國泰 00878 僅此固定示範例外，每日國泰資料仍走官方備援。請先依套件的執行環境安全指引確認工具與 TLS，再執行計算；本工具不構成投資建議。

本版提供36檔公開快照與明確的官方備援清單，新增復華00929、富蘭克林華美00905、台新00936、兆豐00932、玉山009803、第一金00728、摩根00401A、聯博00404A的已驗證來源。尚無公開快照的14檔代表商品與原因見[快照清單](skills/taiwan-etf-lookthrough/references/snapshot-coverage.md)；代表商品支援不等同全市場或整家投信支援。
