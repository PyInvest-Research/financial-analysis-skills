# 內建快照與官方備援

未指定同商品可用本機快照時，本版計算使用套件內的 `scripts/lookthrough/data/snapshots/index.json`；每檔列出實際持股日、原始來源類型及封存內容雜湊。下載後不會自行更新。缺少商品、資料過期或不完整時由 agent 依 [official-fallback.md](official-fallback.md) 查官方。

程式版號與資料包日期分開；純快照更新不升版。資料包 ID 見 skill.json 與本機索引，包含日期及同日內容識別碼。網站僅提供目前資料包；研究請保存下載檔或對應 commit，歷史官方資料保留於研究用 GCS。

## 更新與品質

內建數量不表示支援全市場、每日取得成功或完整持股；未列商品不等於零持股。超過 30 天的資料會保留原日期並附過期天數警告；不改成今天的資料。部分持股、估值缺漏與對帳差異保留可用列並標註。未知市場、權重與期貨金額維持未知。

固定研究與 demo 另保留原始日期，不計入內建快照數量，也不作當期持股。涵蓋率以完整組合市值為分母；六句固定限制仍適用。
