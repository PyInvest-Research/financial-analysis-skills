## 計算與註記

`run_lookthrough(..., validation_policy="annotated")` 是預設。
v1.4.0 的每日 publisher 同樣明確採用 annotated，總額、四捨五入與
完整性差異保留警示；直接呼叫 `validate_snapshot` 仍預設 strict，供診斷比較。
舊 36 檔研究副本繼續以原內容雜湊驗證；最新官方更新使用各自新日期與來源證據。

| 狀況 | 註記模式行為 |
| --- | --- |
| 部分名單、前十大、低台股權重 | 算已知列，標為 `partial_estimate`；保留未知差額，不放大到 100% |
| 權重合計超過 100%、官方逐列與總額不合 | 保留已知有限權重及負差額，明示部分／暫估；不重算成 100% |
| 某列權重缺漏 | 不計該列；保留 null 與未分類差額；指標只描述已算到的公司 |
| 超過 30 日或各 ETF 日期不同 | 保留實際日並警告；不是當期或同日曝險 |
| 官方公布權重分母未完全交叉確認 | 以公布值暫估，列出假設；不拿不同日期 NAV 重算 |
| 0055／0056 | `FundWeights.Summary.fundsize` 與 `PCF.totalav` 有已知差異；沿用公布值並標為 `qualified_estimate` |
| 完整清單支持零台股 | 僅確認該持股日的直接台股現貨為零；不代表沒有台灣經濟曝險 |
| 海外權重或全基金 NAV 未知 | 台股已驗證部分照算，海外未知不補零；有完整市場名單時可確認零台股而不虛構 NAV |
| 只有基金總比例 | 獨立顯示歷史日期、總比例及套用市值的參考金額；不進公司、重疊或有效持股數，不抵減未穿透 |
| 完全缺資料 | 保留全額未穿透，指引 agent 查官方；不輸出假零值 |
| NaN／Inf、負使用者金額、錯單位、重複證券、未來日期、研究雜湊不符 | 拒絕有問題的快照／輸入，其他 ETF 照常計算 |

`result_quality` 顯示 `validated_dated`、`fixed_research`、`partial_estimate`、
`qualified_estimate`、`historical_estimate` 或 `unavailable`。
這是資料資格標籤，不是投資信心分數。若比例／持股不完整，總結應寫
「已計算部分」，不能把 `not_looked_through_value == 0` 當所有權重已知。
未分類差額仍可能含缺漏股票、海外股票、現金及負債，不能統稱現金。

新取得的混合快照用 schema 2，明示 TWSE／TPEx 與海外市場，保留原檔 SHA，
`equity_evidence.complete` 如實填寫、列數與實際股票列數一致。註記模式對
未在固定合約內的快照只用逐列權重，不拿未獨立驗證的聚合金額覆寫結果。
海外識別不能只靠數字代號，ETF 本身不能當普通股遞迴計入公司。

## 009828 與其他總比例參考

009828 尚無本版可用逐股快照。393 檔追蹤表保留 SITCA 2026-09-30
月末台股比例 58.29%，屬前階段研究；本輪 109 檔未新增它的完整持股。
程式只在其無快照時於 `historical_ratio_references` 列出這份參考，
完整部位市值依然未穿透。四捨五入顯示 0.00% 也不證明完整零台股。

## 每日更新與資源

現有 registry 仍為 40 檔 HTTP 候選＋9 檔 official_only；新增 36 檔的
index route 是 `research`，**不加入每日 collector，不增加官方請求**。
publisher 會保留其固定內容及日期，不改成當天。需要更新時由 agent
查官方資料；後續完成新 parser 合約後才能改列每日自動來源。

本次只用既有 Python 標準庫與 openpyxl，沒有新增依賴或 GPU 工作。
固定資料約數百 KB、程序只載入一次；不為每個部位重讀大型研究包。
替代做法是全市場重抓及逐家新 parser，較適合後續持續更新，不是此次
研究匯入的必要成本。
