## 計算與註記

`run_lookthrough(..., validation_policy="annotated")` 是預設。
v1.4.0 的每日 publisher 同樣明確採用 annotated，總額、四捨五入與
完整性差異保留警示；直接呼叫 `validate_snapshot` 仍預設 strict，供診斷比較。
舊 36 檔研究副本繼續以原內容雜湊驗證；最新官方更新使用各自新日期與來源證據。

| 狀況 | 註記模式行為 |
| --- | --- |
| 部分名單、前十大、低台股權重 | 算已知列，標為 `annotated`；保留未知差額，不放大到 100% |
| 權重合計超過 100%、官方逐列與總額不合 | 保留已知有限權重及負差額，明示部分／暫估；不重算成 100% |
| 某列權重缺漏 | 不計該列；保留 null 與未分類差額；指標只描述已算到的公司 |
| 超過 30 日或各 ETF 日期不同 | 保留實際日並警告；不是當期或同日曝險 |
| 官方公布權重分母未完全交叉確認 | 以公布值暫估，列出假設；不拿不同日期 NAV 重算 |
| 0055／0056 | `FundWeights.Summary.fundsize` 與 `PCF.totalav` 有已知差異；沿用公布值並標為 `annotated` |
| 完整清單支持零台股 | 僅確認該持股日的直接台股現貨為零；不代表沒有台灣經濟曝險 |
| 海外權重或全基金 NAV 未知 | 台股已驗證部分照算，海外未知不補零；有完整市場名單時可確認零台股而不虛構 NAV |
| 只有基金總比例 | 獨立顯示歷史日期、總比例及套用市值的參考金額；不進公司、重疊或有效持股數，不抵減未穿透 |
| 完全缺資料 | 保留全額未穿透，指引 agent 查官方；不輸出假零值 |
| NaN／Inf、負使用者金額、錯單位、研究雜湊不符 | 拒絕有問題的快照／輸入，其他 ETF 照常計算 |

`result_quality` 在 annotated 模式顯示 `exact`、`annotated`、`research`、
`estimated_ratio` 或 `unavailable`。strict 保留既有標籤與欄位。
這是資料資格標籤，不是投資信心分數。若比例／持股不完整，總結應寫
「已計算部分」，不能把 `not_looked_through_value == 0` 當所有權重已知。
未分類差額仍可能含缺漏股票、海外股票、現金及負債，不能統稱現金。

新取得的混合快照用 schema 2，明示 TWSE／TPEx 與海外市場，保留原檔 SHA，
`equity_evidence.complete` 如實填寫、列數與實際股票列數一致。註記模式對
未在固定合約內的快照只用逐列權重，不拿未獨立驗證的聚合金額覆寫結果。
海外識別不能只靠數字代號，ETF 本身不能當普通股遞迴計入公司。

### 解讀原則

- 權重沿用來源原值，不歸一化。
- 未知值不補零。
- 期貨名目本金不視為 NAV 資產，也不計入台灣現貨股票。
- 快照不代表當期持倉，也不代表全市場 AUM 排名。
- 本批只公開必要的事實投影，未據此主張來源提供一般再散布授權。

### 產生方式

- 00881 與 00922 重用 PR32 原件，只補上 catalog 明列、原為 official_only 的空索引，不覆蓋既有快照或每日路線。
- 00903 與 00920 以既有 Fubon parser 重播已審核的財務投影。
- 00400A 與 00701 使用已保存、完整展開的官方 DOM。證券代碼由精確官方名錄或同日原生代碼推導。
- 只有精確日期、候選 hash、發布 hash 與逐證券身分全部通過的快照，才會進入 research route。
- 每日更新只保留 hash 完全相符的研究列，不抓取其來源，也不改動原取得時間。

### 發布與索引

`research-publications.json` 記錄各快照的日期與完整 SHA256。下載時會核對候選商品、逐證券身分與金融驗證，不沿用舊研究包的豁免。這些固定發布版本沒有另附套件 fallback 副本；原有歷史研究 catalog 與離線副本維持不變。

```
python -m lookthrough.publish_research --out <root> <snapshot.json> ...
```

此命令只讀取明確指定的本機快照，整批驗證後才寫入 dated、latest 與 index，不會連線至來源。
